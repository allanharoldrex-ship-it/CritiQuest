## Interview STAR — “A product you owned” (CritiQuest)

**Situation:** Schools need critical-thinking practice, but most “AI for homework” tools answer for the student. I wanted portfolio evidence I could own end-to-end for a GenAI / conversational AI PM move.

**Task:** Define a child-safe Socratic product for ages 8–14, ship a zero-cost public MVP, and document the product case (users, principles, safety, architecture, roadmap) without fake traction.

**Action:**
- Framed the core loop: clarify → assumptions → evidence → alternatives → implications → reflect; most turns end in a question.
- Specified age-banded prompts, safety filters (harm, jailbreaks, companion tone), and a mocked teacher-in-the-loop view.
- Chose a zero-cost stack (local Ollama for build; Groq/HF for public demo; heuristic fallback so the demo runs with no keys).
- Wrote the Gradio MVP and interview-ready README case study.

**Result:** A runnable demo + case study suitable for outreach; clear trade-offs and “metrics I would track” instead of invented KPIs. (Update with live HF URL and any real qualitative feedback once available — never fabricate counts.)
